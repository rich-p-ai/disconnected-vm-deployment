VM TOOLS — disconnected OpenShift VM copy
Read this first. Do the steps in order. Do not improvise.

Storage class on these clusters is:  LVM
You must be logged in with oc (cluster-admin) before you run anything.

------------------------------------------------
WHAT THIS IS
------------------------------------------------
Source cluster: export a stopped VM and compress the disks in a Job.
USB:           copy only the compressed bundle (no raw disks).
Dest cluster:  one command seeds the catalog (if needed) and creates the VM.

------------------------------------------------
ON THE BASTION (first time)
------------------------------------------------
  tar -xzf vm-tools-1.0.0.tar.gz
  cd vm-tools
  chmod 0750 build dest
  oc whoami
  oc get storageclass LVM

------------------------------------------------
1. SOURCE CLUSTER — BUILD
------------------------------------------------
Log in to the SOURCE cluster.

  ./build \
    --namespace <source-project> \
    --vm <source-vm-name> \
    --version 0.1.0-test \
    --storage-class LVM \
    --transfer-dir /tmp/vm-transfer

Wait until it prints checksums and USB instructions.

PASS:
  /tmp/vm-transfer/<vm>-0.1.0-test/ contains *.raw.gz and checksums.sha256
  NO *.raw files
  cd /tmp/vm-transfer/<vm>-0.1.0-test && sha256sum -c checksums.sha256

FAIL:
  oc logs -f job/<name-printed-by-script> -n <source-project>
  Copy the last 50 lines and stop. Do not rerun until the old Job/PVC are deleted.

------------------------------------------------
2. USB
------------------------------------------------
Copy the whole directory:

  /tmp/vm-transfer/<vm>-0.1.0-test/

Also copy this vm-tools folder if the dest bastion does not already have it.

Do NOT copy any file ending in .raw

On dest bastion:

  cd /path/to/<vm>-0.1.0-test && sha256sum -c checksums.sha256

------------------------------------------------
3. DEST CLUSTER — SEED + CREATE VM
------------------------------------------------
Log in to the DEST cluster.

  oc get ns <user-project> || oc new-project <user-project>

  ./dest \
    --bundle-path /path/to/<vm>-0.1.0-test \
    --storage-class LVM \
    --catalog-namespace vm-catalog \
    --namespace <user-project> \
    --vm-name <new-vm-name>

Leave off --start unless you were told to power the VM on.

PASS:
  Job completes
  oc get vm <new-vm-name> -n <user-project>
  VM is Stopped unless you used --start

A message about clone failing and falling back to image-upload is normal on LVM.

------------------------------------------------
4. IF SOMETHING FAILS
------------------------------------------------
Do not run the same command again until you delete the previous Job and work PVC.
The script prints the exact oc delete commands at the end (and on some failures).

Use a small test VM first (one disk, 20-40Gi). Do not start with a production image.

------------------------------------------------
OPTIONAL — POWER ON
------------------------------------------------
  virtctl start vm <new-vm-name> -n <user-project>
  oc get vmi <new-vm-name> -n <user-project>
