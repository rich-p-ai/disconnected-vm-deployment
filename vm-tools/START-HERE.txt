START HERE

1. Read HOW-TO.txt in this same folder.
2. Do Part A on the first cluster.
3. Copy the small files on a USB stick. No .raw files.
4. Do Part C on the next cluster.

You need:
  - this vm-tools folder
  - oc login as cluster admin
  - disk class named lvm

Do not use sudo.

Quick commands (put in your names):

  chmod 0750 build dest cleanup

  ./cleanup

  ./build --namespace <project> --vm <vm> --version 0.1.0 --storage-class lvm --transfer-dir /tmp/vm-transfer

  ./dest --bundle-path /path/to/<vm>-0.1.0 --storage-class lvm --catalog-namespace vm-catalog --namespace <user-project> --vm-name <new-vm>
