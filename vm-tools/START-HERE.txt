VM TOOLS
This folder is the whole toolkit. Copy only this folder to the bastion.
Edit files in this folder. Do not hunt through the rest of the repo.

Storage class: LVM
Need: oc login as cluster-admin, then chmod 0750 build dest

SOURCE (logged into source cluster)
  ./build --namespace <project> --vm <vm> --version 0.1.0-test --storage-class LVM --transfer-dir /tmp/vm-transfer

USB
  Copy /tmp/vm-transfer/<vm>-0.1.0-test/  (*.raw.gz only, no *.raw)
  On dest: cd that dir && sha256sum -c checksums.sha256

DEST (logged into dest cluster)
  oc get ns <user-project> || oc new-project <user-project>
  ./dest --bundle-path /path/to/<vm>-0.1.0-test --storage-class LVM --catalog-namespace vm-catalog --namespace <user-project> --vm-name <new-vm>

Leave off --start unless told to power the VM on.
Clone failure then image-upload is normal on LVM.
